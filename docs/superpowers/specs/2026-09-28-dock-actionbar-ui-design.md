# IDE-подобная нижняя панель и доки: полный дизайн

Дата: 2026-09-28
Ветка-реализация: `refactor/dock-ui` (отдельная от `feat/github-sync`)
Бэкенд-фундамент: уже в `feat/github-sync` (коммит `b4e3b9e` — log/diff/commit-files endpoints)

## Цель

Перейти от «панелей на страницах» к IDE-модели (VS Code / Zed): тонкая нижняя
action-bar + доки-сайдбары с слотами. Git перестаёт быть полосой сверху и
получает полноценный интерфейс с диффом, историей коммитов и ветками. Теория,
задачи и AI-ассистент получают единый механизм видимости/закрепления.

## Ключевое правило доков (главное архитектурное решение)

**Слева и справа — по одному док-слоту.** Панели (дерево / git / AI) закреплены
на одной из сторон; на стороне не может быть двух панелей одновременно.

Поведение кнопки на нижней панели:

| Действие | Результат |
|---|---|
| ЛКМ на кнопку панели, чья сторона свободна | панель открывается на своей стороне |
| ЛКМ на кнопку другой панели, закреплённой на той же стороне | текущий док закрывается, открывается новая панель (замещение в слоте) |
| ЛКМ на кнопку открытой панели | док закрывается |
| ПКМ на любую кнопку | контекстное меню: Dock Left / Dock Right (+ Floating для AI), «Скрыть кнопку» |

Пример: дерево и git оба закреплены слева. Дерево открыто → ЛКМ по git
закрывает дерево и открывает git. ЛКМ по открытому git — закрывает.

Центральные табы (теория/код) — **основные и вечные**, доки их только обрамляют.

## Компоненты

### 1. Нижняя action-bar (~36px, fixed bottom)

Зоны: слева — кнопки панелей (иконки отражают сторону закрепления маленькой
точкой слева/справа от иконки), центр — переключатель табов «Теория/Код»
(сегмент-контрол, соответствует существующим табам), справа — AI.

Активная панель — подсветка иконки (bg-brand/15 text-brand, как текущий
GitTreeToggle). Кнопки появляются только там, где контекст уместен:
git-кнопка рендерится только для git-курсов (status endpoint уже решает),
«Теория/Код» — только на страницах юнита/задачи.

Панель показывается на маршрутах `/courses/*` (course/unit/task/theory).
Высота контента центральной области уменьшается на 36px.

### 2. Контекстное меню кнопки (ПКМ)

Пункты: `Dock Left` / `Dock Right` (галочка на текущей стороне), разделитель,
`Floating` (только для AI), разделитель, `Скрыть кнопку`.

Анкерится к кнопке, закрывается по клику вне / Esc / выбору пункта.
Позиция запоминается в localStorage (`cf:dock:<panel>` = `left|right|float`,
AI дополнительно использует существующий `cf_ai_mode`).

### 3. Git-док (signature-элемент)

Каркас (ширина как у текущего сайдбара, resizable 200..650). Секции сверху
вниз:

1. **Шапка**: `git status` — ветка, короткий коммит, dirty-точка (warn) с
   тултипом.
2. **Обновить**: кнопка → существующий PullModeDialog (Объединить/Затереть/
   Отмена).
3. **Изменения**: `GET .../git/diff` (готово, `b4e3b9e`). Строка = бейдж
   M/D/A/R (цвета: M=warn, D=err, A=ok, R=brand) + путь + счётчик строк.
   Клик по строке → инлайн-раскрытие ханков (Zed-стиль): моно-шрифт, `-`
   строки красные (bg-err/10), `+` зелёные (bg-ok/10), `@@`-заголовки
   приглушены (tx-3). Повторный клик — свернуть. Секция скрыта, когда
   изменённых файлов 0.
4. **Ветки**: `GET .../git/branches` — текущая с точкой, остальные
   радио-стилем; выбор + «Переключить» → существующая логика (dirty →
   ConfirmDialog с force, 422 → откат с перерегистрацией).
5. **История**: `GET .../git/log?limit=30` — хэш (tx-3, моно), subject,
   человекочитаемое время («3 мин назад», ru). Клик по коммиту →
   `GET .../git/log/{commit}` → аккордеон со списком файлов коммита.

**Полноценный дифф «было — стало»** (режим 2): открывается из инлайн-диффа
кнопкой «Открыть в редакторе». Центральная область делится на две колонки-
таба: левая «Было» (версия из HEAD), правая «Стало» (рабочая версия).
v1 — read-only CodeMirror с diff-подсветкой строк; для «было» нужен новый
бэкенд-endpoint `GET /courses/{slug}/git/file?ref=HEAD&path=...`.
Правки из диффа — future.

### 4. Дерево-док

Существующий `Sidebar` из CoursePage переносится в док-контейнер без
изменений содержимого (СОДЕРЖАНИЕ, теги, прогресс-бар, resize-ручка).
Git-иконка в хедере дерева (коммит `aa37eef`) удаляется — git живёт в своём
доке.

### 5. AI-док

Существующий AIAssist уже имеет docked/floating/closed (`cf_ai_mode`).
Кнопка на action bar: ЛКМ — toggle closed ↔ последний режим; ПКМ — меню с
`Docked / Floating` и `Dock Left / Dock Right`. Floating-окно остаётся как
есть (floating = не занимает док-слот).

## Архитектура фронтенда

### Состояние (новый контекст `DockContext`)

```ts
interface DockState {
  // где закреплена каждая панель (персистентно)
  position: { tree: 'left' | 'right'; git: 'left' | 'right'; ai: 'left' | 'right' | 'float' };
  // что открыто в слоте (runtime, сессия)
  left: 'tree' | 'git' | 'ai' | null;
  right: 'tree' | 'git' | 'ai' | null;
  aiMode: 'docked' | 'floating' | 'closed'; // синхронизирован с cf_ai_mode
}
```

Инвариант: слот `left`/`right` содержит только панель, чей `position` — эта
сторона. Открытие панели: если её сторона занята другой — замещение (старая
закрывается).

localStorage: `cf:dock:tree` = `'left'|'right'` (per-panel, персистентно);
слоты — runtime-only; AI — `cf_ai_mode` + `cf:dock:ai`.

### Компоненты

```
frontend/src/
  layout/
    ActionBar.tsx          # нижняя панель (кнопки, зоны, контекст-меню)
    DockLayout.tsx         # каркас: left dock | центр | right dock + bar
    DockPanel.tsx          # обёртка дока (resize, заголовок, закрытие)
    DockContextMenu.tsx    # ПКМ-меню
  git/
    GitDockPanel.tsx       # секции: шапка, изменения+дифф, ветки, история
    GitDiffInline.tsx      # инлайн-ханки
    GitHistoryList.tsx     # коммиты + аккордеон файлов
```

Существующие `Sidebar` и `AIAssist` переезжают в DockPanel-обёртки.
CoursePage/TaskPage/TheoryPage лишаются собственных сайдбар-обёрток и
рендерятся в центральный слот `DockLayout`.

### API-клиент (бэкенд готов в `b4e3b9e`)

```ts
gitLog: (slug: string, limit = 30) => get<GitLogResp>(`/courses/${slug}/git/log?limit=${limit}`),
gitCommitFiles: (slug: string, commit: string) => get<GitCommitFilesResp>(`/courses/${slug}/git/log/${commit}`),
gitDiff: (slug: string) => get<GitDiffResp>(`/courses/${slug}/git/diff`),
```

Типы: `GitLogResp {commits: {hash, subject, author, time}[]}`,
`GitCommitFilesResp {files: string[]}`,
`GitDiffResp {files: {path, status: 'M'|'D'|'A'|'R', hunks: string[]}[]}`.

## Ограничения / решения

- Узкая ширина (<768px): доки — overlay поверх контента (не push), action
  bar остаётся. Не блокер для v1.
- Reduced motion: без анимаций доков (только opacity fade).
- Клавиатура: Alt+1/2/3 — toggle дерева/git/AI (как VS Code).
- «Скрыть кнопку»: скрывает кнопку из action bar (`cf:dock:hidden`),
  вернуть — через настройки (раздел «Интерфейс»).
